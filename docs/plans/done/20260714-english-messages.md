# アプリ内で表示するメッセージを英語にする

- 作成日: 2026-07-14
- ステータス: ドラフト

## 概要

openshoki がユーザーに見せる日本語のメッセージを英語に統一する。対象は GUI に表示する
文言（Slint ウィンドウ・トレイメニュー・ツールチップ・メニューバー）と、ターミナルに出る
ログ／エラーメッセージ（`eprintln!` / `println!` と `Err(...)` に渡す文字列、および
`expect!` / `panic!` のメッセージ）。ユーザーが目にする文言を一貫して英語にするのが狙い。
ソース内の日本語コメント（doc コメント含む）は「表示するメッセージ」ではないため対象外。

## 背景・前提（コンテキスト）

- openshoki はメニューバー／タスクバーに常駐する Rust 製録音アプリ。GUI は Slint、トレイ常駐は
  `tray-icon`（`docs/CONTEXT.md`）。ユーザーとの接点は「トレイメニュー」「メニューバーの
  経過時間・アイコン」「設定ウィンドウ」「ツールチップ」、そして開発・運用時に見る
  標準出力/標準エラーのログ。
- i18n（多言語切替）の仕組みは無く、文言はすべてソースにハードコードされている。今回は
  ロケール切替を導入せず、日本語リテラルを英語リテラルに置き換える単純な方針とする（後述）。
- エラーハンドリング方針上、失敗は握りつぶさず `eprintln!` でログに残し常駐を続ける
  （`docs/rules/error-handling.md` 参照コメントが各所にある）。この「ログに残す」文言が
  英語化対象のログメッセージにあたる。

## 要件

- GUI に表示される日本語文言をすべて英語にする。
- ターミナルに出るログ／エラー文言（`eprintln!` / `println!` / `Err(...)` 文字列 /
  `expect` / `panic!` メッセージ）をすべて英語にする。
- コード中の日本語コメント・doc コメントは変更しない（表示メッセージではないため）。
- 既存の挙動（メニュー項目のラベル切替ロジック、経過時間フォーマット、色計算など）は変えない。
  文言の言語だけを変える。
- スコープ外:
  - i18n / ロケール切替機構の導入。
  - `docs/` 配下のドキュメント（CONTEXT.md 等）の英語化。
  - ウィンドウタイトル `"openshoki"`・トレイのアイドル時ツールチップ `"openshoki"` など、
    すでに製品名で言語非依存の文字列（変更不要）。

## 確定した論点

- **対象範囲は「UI 表示文言 + ログ／エラー」の両方**（ユーザーへの確認で確定）。
  ソースコメントは対象外。
- **専門用語・固有名はそのまま**: `openshoki` は製品名なので翻訳しない。ファイル名
  （`mic.mp3` 等）や `OSStatus` 等の識別子も原語のまま英文に埋め込む。
- **i18n は導入しない**: 常駐型の小規模アプリで現状 UI 言語は 1 つ。文言リテラルの直接
  置換にとどめ、翻訳テーブルやロケール判定は持ち込まない（過剰設計を避ける）。
- **CONTEXT.md の Language（用語）は日本語のまま**: 「常駐」「録音セッション」はプラン・
  issue・PR・コメントで使う内部用語であり、UI 文言ではない。英語 UI 文言との対応は
  実装時の翻訳で吸収する（例: 「録音を開始」→ `Start Recording`）。

## 実装方針

日本語文字列リテラルを英語リテラルへ 1 対 1 で置換する。挙動に関わるロジック・定数の
構造（`SETTINGS_LABEL_OPEN` などの定数名や参照箇所）は変えず、値の文字列だけを差し替える。
`format!` に埋め込む変数（`{err}`, `{status}`, `{}` など）はそのまま残し、周囲の日本語を
英語にする。コメント行（`//`, `//!`, `///`）は一切触らない。

英語文言のトーンは簡潔・平易な UI 英語で統一する（例: メニューは動詞句 `Start Recording`、
ログは平叙文 `Failed to …`）。

### 主な文言の対応（英語は実装時の確定案）

**UI（`ui/app-window.slint`）**
- `openshoki 設定` → `openshoki Settings`
- `録音ファイルの保存先` → `Recording save location`
- `フォルダを選択` → `Choose Folder`
- `マイク使用時に自動録音（macOS）` → `Auto-record when the microphone is in use (macOS)`
- `title: "openshoki"` は変更しない。

**トレイ（`src/tray.rs` の定数・ツールチップ）**
- `設定を開く` → `Open Settings`
- `設定を閉じる` → `Close Settings`
- `録音を開始` → `Start Recording`
- `録音を停止` → `Stop Recording`
- `終了` → `Quit`
- `openshoki — 録音中…` → `openshoki — Recording…`
- `TOOLTIP_IDLE = "openshoki"` は変更しない。

**ログ／エラー（`eprintln!` / `println!` / `Err(...)` / `expect` / `panic!`）**
- `src/main.rs`: 設定保存失敗・監視開始不可・イベントループ終了失敗・録音開始/停止失敗・
  ウィンドウ表示/非表示失敗・`録音を保存した（{} ファイル）`・`expect("main は…")` など全 9 箇所。
- `src/tray.rs`: トレイアイコン／ツールチップ更新失敗（4 箇所）・`expect("RGBA バッファ…")`。
- `src/recorder.rs`: システム音声継続・停止保存失敗・未対応フォーマット/チャンネル・
  入力ストリームエラー・writer 終了/パニック・空ファイル削除失敗（計 8 箇所）。
- `src/mic_monitor.rs`: リスナー登録/解除失敗・既定入力デバイス取得失敗/未設定（4 箇所）。
- `src/system_audio.rs`: 共有コンテンツ取得失敗・ディスプレイ未検出・キャプチャ開始/停止失敗（4 箇所）。
- `src/config.rs`: 設定/ユーザーディレクトリ取得不可のフォールバック（2 箇所）、および
  テストコード内の `expect("シリアライズは成功するはず")` 等（3 箇所）も英語化して統一する。

（`grep -rn '[ぁ-んァ-ヶ一-龠]'` で拾える文字列のうち、コメント行を除いたリテラルすべてが対象。）

## 実装ステップ

1. `ui/app-window.slint` の表示文言を英語化する。`cargo run`（または `cargo dev`）で設定
   ウィンドウを開き、全ラベル・ボタン・チェックボックスが英語で表示されることを確認。
2. `src/tray.rs` の定数（`SETTINGS_LABEL_*` / `RECORD_LABEL_*`）・`"終了"`・`TOOLTIP_RECORDING`
   を英語化する。トレイメニューの各項目・録音中ツールチップが英語になることを実機で確認。
3. `src/main.rs` のログ／エラー／`expect` メッセージを英語化する。
4. `src/recorder.rs` / `src/mic_monitor.rs` / `src/system_audio.rs` / `src/config.rs`（テスト
   含む）のログ／エラー／`expect` メッセージを英語化する。
5. 検証:
   - `grep -rn '[ぁ-んァ-ヶ一-龠]' src ui --include='*.rs' --include='*.slint'` の結果が
     **コメント行（`//` / `//!` / `///`）のみ**になり、文字列リテラルに日本語が残っていない
     ことを確認する。
   - `cargo build` と `cargo test`（tray.rs の既存テスト等）が通ることを確認する。
   - `cargo run` でトレイメニュー・設定ウィンドウ・録音開始/停止時のメニューバー表示・
     ツールチップが英語になっていることを目視確認する。

## 影響範囲・リスク

- 影響を受けるファイル: `ui/app-window.slint`, `src/tray.rs`, `src/main.rs`,
  `src/recorder.rs`, `src/mic_monitor.rs`, `src/system_audio.rs`, `src/config.rs`。
- リスクと対策:
  - **文字列リテラルとコメントの取り違え**: コメント（`//` 系）は絶対に変更しない。
    最終 grep でリテラルのみ英語化されたことを機械的に確認する。
  - **メニューバー幅への影響（macOS）**: 英語文言は日本語より長くなる場合があるが、対象は
    主に固定ラベルで、メニューバー常時表示は経過時間（数値）のみ。実機表示で崩れないか確認する。
  - **既存テストの破損**: `src/tray.rs` のテストは `format_elapsed` / `recording_color`
    （数値）のみを検証し文言に依存しないため影響なし。念のため `cargo test` で確認する。
